# Legal Aid Lite ⚖️

Legal Aid Lite is an Agentic AI-powered legal assistant designed to simplify complex legal contracts and identify hidden clauses, penalty terms, and important deadlines.

## Features
- Upload legal contracts in PDF format
- AI-powered contract analysis
- Plain-English explanations
- Hidden clause and penalty detection
- Semantic search using RAG
- Interactive chatbot interface

## Technologies Used
- Python
- Streamlit
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq API
- NLP
- RAG Architecture

## How It Works
1. Upload a legal contract
2. System converts document into embeddings
3. FAISS vector database stores document chunks
4. AI retrieves relevant legal clauses
5. LLM generates simplified legal explanations
